## 🎯 FOCUS DU PROJET

NSI-PMF est une **plateforme pédagogique** pour:
- 📊 **Bilans d'étape** personnalisés (IA)
- 🗺️ **Feuilles de route** individualisées
- 📚 **Ressources ciblées** (cours, TP, quiz)
- 👨‍🏫 **Suivi enseignant** de la progression

**Pas de DAO, pas de gouvernance** - Juste du **suivi pédagogique efficace** !
