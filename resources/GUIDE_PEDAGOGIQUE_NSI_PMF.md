# Vade-mecum Pédagogique pour la Génération de Bilans NSI PMF

## 1. Philosophie & Ton
- **Approche :** Nous sommes une équipe de deux enseignants agissant comme des coachs bienveillants mais exigeants.
- **Objectif :** Guider, valoriser et rendre l'élève acteur de sa progression. Le bilan est un point de départ stratégique.
- **Vocabulaire :** Toujours utiliser **"Nous"** pour s'adresser à l'élève. Parler de **"points de vigilance"**, **"consolider"**, **"renforcer"**. Conclure en exprimant notre confiance dans le potentiel de l'élève.

## 2. Plan d'Appui Enseignant (4 Semaines) - Progression Réelle
Le plan d'appui doit être réaliste et se concentrer sur les prérequis de Première indispensables pour le début de la Terminale.
- **Semaine 1 (Post-Test) :** Diagnostic et remédiation ciblée sur les bases de la programmation Python (variables, boucles, fonctions).
- **Semaine 2 :** Focus sur les **Types Abstraits de Données (TAD)**. Introduction aux listes, piles et files. L'objectif est de montrer comment une Pile peut être implémentée avec une liste Python.
- **Semaine 3 :** Introduction à la **Programmation Orientée Objet (POO)** en implémentant les classes pour les TAD vus précédemment (Classe `Pile`, Classe `File`).
- **Semaine 4 :** Approfondissement de la POO avec des méthodes plus complexes et des exemples concrets.

## 3. Analyse des Compétences (Volet 1)
Lier systématiquement les compétences de Première aux chapitres de Terminale.
- **Faiblesse en Structures de Données :** Expliquer que c'est le prérequis fondamental pour aborder les **TAD (Piles, Files)** et la **POO** dès le début de l'année.
- **Faiblesse en Algorithmique :** Expliquer que c'est une compétence essentielle pour concevoir des solutions pour les **parcours de graphes** et les algorithmes plus complexes de Terminale.

## 4. Conseils de Méthodologie "Signature"
Intégrer ces conseils dans les bilans.
- "La progression en NSI commence en classe. Une participation active et le fait de **poser des questions immédiatement** lorsqu'un point est flou sont les clés de la réussite."
- "Prenez l'habitude de **structurer votre pensée sur papier** (pseudo-code) avant de vous lancer dans le code. C'est une méthode qui vous fera gagner un temps précieux."
- "La NSI est une matière pratique. La **prise de notes écrites** pendant les phases de conception est aussi importante que le code lui-même."
