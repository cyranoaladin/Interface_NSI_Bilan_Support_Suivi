## 🚀 Installation Rapide

```bash
# 1. Extraire l'archive
unzip site-nsi-tp-complet.zip
cd site-nsi-tp

# 2. Installer les dépendances
pnpm install

# 3. Lancer le serveur de développement
pnpm dev

# 4. Ouvrir http://localhost:5173
```
